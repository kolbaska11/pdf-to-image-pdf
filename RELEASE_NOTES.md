# PDF Rasterizer — v1.0.0

Первый публичный выпуск. Пакетное преобразование PDF в PDF со страницами-картинками: 100/150/200 DPI и сохранение размеров страниц.

## Установка и запуск

1. Скачайте **`pdf-to-image-pdf-v1.0.0.zip`** из Assets этого релиза.
2. Распакуйте ZIP целиком, включая папку `assets`.
3. Установите Python 3.11 или 3.12 (64-bit) с Tcl/Tk.
4. Запустите `start_windows.bat`. При первом запуске создаётся .venv и устанавливаются зависимости; нужен интернет.

Ручной запуск из папки проекта:

```powershell
python -m pip install -r requirements.txt
python pdf_to_image_pdf.py
```

## Зависимости

| Компонент | Назначение |
|---|---|
| `PyMuPDF` | Рендер страниц и сборка нового PDF |

## Исправления и сохранённые функции

Существующие PDF-результаты сохраняются: добавлен числовой суффикс при совпадении имени. Изменение списка файлов во время обработки заблокировано. Основные функции исходного приложения сохранены.

## Ограничения

Изображения формируются в RGB с белым непрозрачным фоном. Размеры видимых страниц и порядок сохраняются; отдельные печатные боксы, закладки, ссылки, формы, подписи и исходная структура PDF не переносятся. OCR отсутствует. Защищённые паролем PDF отклоняются. Размер результата может вырасти; большие страницы при 200 DPI требуют много памяти. Во время обработки дождитесь окончания перед закрытием окна.

Полный Windows GUI вручную не проверен. Подробный объём проверки — [docs/VALIDATION.md](https://github.com/kolbaska11/pdf-to-image-pdf/blob/v1.0.0/docs/VALIDATION.md).

ZIP содержит Python-исходник, Windows-запускатор, зависимости, русскую документацию и JPG-обложку. Установщик Python, EXE и сторонние модели в архив не включены.
