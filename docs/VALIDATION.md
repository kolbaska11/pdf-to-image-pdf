# Проверка v1.0.0

## Среда и границы проверки

Python 3.12.14, Linux. Проверены синтаксис всех Python-исходников и импорт прямых зависимостей. Windows BAT проверен по содержимому (кавычки в путях, CRLF, обработка ошибок); запуск в Windows и полный ручной сценарий GUI не выполнялись.

## Выполнено

- Реальная растеризация трёхстраничного PDF при 100, 150 и 200 DPI: порядок и размеры страниц сохранены, на странице одно изображение, выделяемого текста нет.

- Предыдущий результат сохранён; повторные запуски создают _2/_3/_4. PDF с паролем даёт ошибку; тест использует ядро без окна Tkinter.

## Зависимости в проверочной среде

- `PyMuPDF 1.26.6`

Версии в requirements.txt не закреплены: перечислены прямые зависимости. Указанные выше версии подтверждают проверенную среду, а не обещание совместимости со всеми будущими выпусками.

## Публикационная проверка

Перед загрузкой просмотрены исходники, зависимости, запускатор, README, обложка и workflow. Токенов, паролей и личных файлов среди публикуемых материалов не обнаружено. Лицензия не добавлялась: выбранные условия использования не согласованы. Синтаксическая проверка также выполняется в GitHub Actions перед созданием релиза. ZIP формируется из Git-снимка без .git, .venv и кэшей Python и проверяется командой unzip -t.

## Изменения к исходному архиву

Существующие PDF-результаты сохраняются: добавлен числовой суффикс при совпадении имени. Изменение списка файлов во время обработки заблокировано.
